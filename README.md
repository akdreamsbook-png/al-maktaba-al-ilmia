# المكتبة العلمية لفضيلة الشيخ أبي أنس محمد مصطفى صار

نسخة للعرض على GitHub Pages: دروس علمية، خُطب، محاضرات عامة، وكتب وبحوث — عربي/فرنسي (AR | FR).

- **ملاحظة صادقة:** هذه نسخة للقراءة فقط. لوحة التحكم ورفع الملفات يعملان محليًّا عبر
  `python3 server.py 8000`، وبعد إضافة محتوى يُعاد توليد هذه النسخة بأمر `./publish.sh`.
- البيانات تُقرأ من `assets/data/*.json` المولَّدة من القاعدة المحلية، والمسجلَّات في `uploads/`.
